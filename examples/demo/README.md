# Public demonstration fixtures

These examples contain no real user data. The server's `--demo` mode creates a
private copy of a small text repository and uses a fixed public-page fixture.
The model is deterministic; all tools, SQLite transactions, workflow plans,
events, UI and artifact operations use the real application implementation.

Try these prompts:

- Discussion: compare implementing an Agent Loop with adopting a framework.
- Research: research when multi-agent collaboration helps, with limitations.
- Code analysis: explain how the bundled repository separates identity and role.
- Routing: 布偶猫帮我研究一下协作方法。
- Explicit handoff: 布偶猫查资料，缅因猫复核，橘猫汇总。

Demo findings demonstrate interaction contracts, not real-provider accuracy.
