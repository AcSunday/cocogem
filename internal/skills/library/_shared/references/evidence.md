# 证据与限制

交付里"已完成"的每一句都要有可追溯来源；无法验证的部分必须显式列出，而不是省略。

## 可用层级

- **T0**：用户原话、已接受的修订、真实文件字节。
- **T1**：宿主捕获的 `diff`、`test`、`image`、`git_inspect`、`preview_page` 结果。
- **T2**：成员自己的描述、搜索摘要、原生 CLI 的加工后输出。

## 规则

- 只有 T0/T1 能支撑"已验证"；T2 只能作为线索。
- 测试必须是在最后一次写入之后、针对当前树跑通的；改完文件再引用旧测试不算验证。
- 截图只证明渲染结果，不证明逻辑正确；纯后端、CLI 或算法改动不需要截图。
- 无法取得浏览器内核、测试工具链或网络时，如实说明 `browser_engine_unavailable`、沙箱不可用或网络受限，不猜测结果。
- 失败、超时、被杀的进程记录为失败，不因"看起来对"改成通过。
