# 汇总结果

先核对工作包中的任务状态和确切产物版本。只把实际送达且状态允许的结果作为已完成贡献；提交回执、排队任务和部分输出不能代替终态。

1. 对照用户问题和验收条件组织结果，明确引用哪些成员任务、来源和产物版本。合并重复信息，不抹去独立复核指出的反例或争议。
2. 区分证据支持的事实、推论和未验证项。重要结论应有当前可用来源，缺少证据时明确标记，不能编造引用。
3. 按本步要求使用 `publish_artifact` 提交允许类型的产物，并处理工具校验错误。工具确认前不能声称正式产物已发布；没有该权限时给出普通结论并说明限制。
4. 在交付中说明范围、方法、主要发现、分歧、失败或未完成任务、限制和必要下一步。复核缺失或未通过时如实保留，不描述为全部验收通过。

汇总达到当前交付条件后结束。只有明确缺口且剩余权限与预算允许时才提出后续任务；不要为获得一致意见反复转交。
