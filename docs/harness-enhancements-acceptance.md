## 验收发现并修复

- 图片校验只认文件头：改为有界完整解码，拒绝截断图片及 MIME 不匹配。
- 增量和最终快照重复或冲突仍成功：改为有界前缀校验；冲突按协议失败处理。
- 恢复与软删除并发导致已删会话重新排队：在最终事务和派发时复核可见性。
- 清理回滚计数、恢复再删除期间的旧到期候选：仅在提交后报告清理数，最终写入前重新判断当前到期时间。
- 重试超出四次或混合认证/不确定进程错误仍重放：修正持久计数与完整错误树判断。
- 真实 Claude `api_retry.error` 为字符串导致解码失败：兼容字符串与对象，保留真实错误分类。
- 未填写思考等级时遗漏本机默认：按白名单转交已有 Codex/Gemini 推理配置，显式成员设置优先。
- 畸形 mention URL 导致页面异常、新版本成员被本地缓存遮蔽：加入安全解码和按 revision 接受权威更新的回归。
- 首条消息的 @ 简介被顶栏裁切：改用固定浮层与窗口内定位，加入浏览器矩形边界与实际遮挡检查。
