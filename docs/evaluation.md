# Public evaluation protocol

Use only public or synthetic data. Run the same question with one member and
with the corresponding collaboration workflow. Record provider, model,
application revision, input sources, output artifacts, elapsed time and actual
reported usage. Missing usage is unknown, not zero. Archive source captures.

| Task | Checks |
| --- | --- |
| Compare native loops and Agent CLIs | States tradeoffs, names assumptions, preserves disagreement |
| Research multi-agent collaboration | Captures actual originals, distinguishes snippets, dates and inference |
| Explain the public code fixture | Cites real file/line captures, avoids claiming execution |
| Negative routing examples | Negation, hypotheses and quoted instructions do not dispatch |
| Missing or blocked sources | Reports uncertainty instead of inventing citations |

Review correctness, unsupported claims, omissions and useful disagreement.
Automated test fixtures validate workflow behavior only. No real-provider quality
score is currently claimed. Real smoke tests require explicit provider setup;
never use private project data as an automatic evaluation fixture.
