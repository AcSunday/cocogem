# 协作产品改造验收记录

日期：2026-10-28。实现由本机 Claude Code 完成，Codex 独立审查和验收；两轮真实 Gemini CLI 讨论已就以下边界达成一致：复杂讨论先独立思考再交叉质询，允许明确保留分歧，简单任务可以直接短答。此记录使用合成临时项目与测试数据，不含真实用户会话、数据库或凭证。

## 13 项改动

| 项目 | 最终行为 |
| --- | --- |
| 1 讨论与短答 | 复杂讨论按独立观点、串行质询、综合草案、原作者结构化复查、最终交付执行，2–4 位成员最多 14 步。确认不等于事实证据；未收敛时保留分歧。简单自由协作可直接一条短答完成。 |
| 2 最终产物 | `Run.delivery` 保存指定最终消息和精确产物版本；中间步骤不能发布正式产物。多显式目标均保留各自的最终答复；旧历史不猜测交付。 |
| 3 CLI 通知 | 无影响的协议通知不进入用户过程视图；错误、能力降级和需处理的状态继续显示。 |
| 4 自动折叠 | 成功且有权威交付引用时，整轮中间消息和步骤默认收起，最终交付保留在外；手动选择按空间、会话、Run 本地保存。失败、取消、中断与缺交付引用的旧历史保持展开。 |
| 5 冗余成员栏 | 移除右侧成员页签；身份与执行状态留在消息、运行状态和空间授权中。 |
| 6 工程协作 | 新入口支持默认只读分析和显式开发。开发按实现、独立复核、修复复测、最终复核执行；写入、局部修改、测试均使用受控宿主工具。旧 `code_analysis` 兼容只读。 |
| 7 会话菜单 | 悬浮或键盘聚焦时出现更多菜单，可重命名、删除；触屏保留可达入口。仅改标题不改成员或工作方式。 |
| 8 独立设置 | 全局设置分成员、协作、服务；可编辑成员及内置头像、默认协调者、各模式默认分工。默认值仅在本空间与已授权名单内生效。 |
| 9 自由协作分流 | 默认协调者在当前调用直接回答、有限委派，或通过 `choose_workflow` 选择真实讨论、研究、工程分析计划；选择及原因持久化。自动选工程仅授权分析。 |
| 10 消息模型 | 名称后括号显示该条消息对应 Attempt 的请求/实际模型快照，不用最新成员设置重写历史。CLI 未提供具体模型时显示默认/未知状态。 |
| 11 空间入口 | 顶部成员入口只管理空间成员关系、启用和工具授权；全局档案移入独立设置。 |
| 12 输入区分工 | 移除会话分工按钮和局部配置状态；服务端消费全局默认，仍支持 @ 与自然语言临时路由。工程动作选择不编辑分工。 |
| 13 外观控件 | 统一外观控件高度、文字对齐及箭头间距。 |

## 真实模型与宿主证据

- 默认自由协作的石头剪刀布：真实 Claude CLI 返回“你出剪刀，我赢。”，约 5.96 秒；一条回复、一步、`method=direct`，没有模式选择或产物。协调者当时具备选模式工具。
- 指定讨论：真实 Claude 与 Gemini 完成两人八步讨论，约 193.7 秒；结构化复查与分歧进入最终交付。
- 自动选模式：真实协调者调用 `choose_workflow` 后完成根规划步骤与八步讨论，约 301.7 秒；原始输入仍为自由协作，选择和最终消息/产物版本均已持久化。首次实跑曾直接作答而未调用选择工具；已加强明确请求多人方法时的指导。模型判断仍具有随机性，不能据一次通过声称每个问题都自动选对。
- 工程开发的真实模型验收使用临时 Go `Add` 错误。整合后的主分支实跑约 88.3 秒：两个真实 Claude CLI 成员完成四步，通过 `patch_file` 修复、四次宿主测试退出码为 0，最终仅一份 `engineering_report`，引用真实 diff 和成功测试。最终复核第一次发布被门禁拒绝，模型修正后通过；没有关闭门禁或伪造测试成功。
- macOS 宿主边界实测包含真实 Go/npm 测试、工程外读写、敏感文件及未来创建的敏感路径、大小写变体、网络连接与监听、系统辅助程序、取消/超时及后代进程收敛。测试前后工程摘要不一致时，退出码仍如实记录，但该次测试不能作为验证交付的证据。
- 原生 CLI 测试复用已有连接与默认模型；验收所需临时环境仅影响子进程，没有写用户 CLI 配置或新增认证要求。

## 验证入口

最终整合验证：完整 `make test` 通过（含 Go race、CLI 集成、前端 24 个测试文件共 176 项），生产构建通过，7 项 Chrome 端到端测试全部通过（约 29.1 秒），API 与 TypeScript 重新生成后无漂移。Codex 在隔离预览中手工验证了默认工程动作只读、独立全局分工设置、头像配置后发送、成功整轮折叠及手动展开后刷新保留。

- `GOFLAGS=-p=1 make test`：脚本测试、格式、vet、Go race、原生 CLI 集成测试、前端 lint/typecheck/行为测试。
- `make build` 与 `make check-contract`：生产构建与生成 API/类型漂移。
- `PLAYWRIGHT_CHANNEL=chrome npx playwright test`：隔离服务与临时数据下的浏览器验收。
- `COCOGEM_CHECK_LIVE_DISCUSSION=1` 启用真实讨论；可加 `COCOGEM_LIVE_COORDINATOR_SELECTION=1` 验证自动选方法，或 `COCOGEM_LIVE_QUICK_ONLY=1` 仅验收默认短答。
- `COCOGEM_CHECK_LIVE_ENGINEERING=1` 启用真实开发验收；仅 macOS 已验证宿主边界下执行。

## 实际边界

- 头像为 8 个内置图案；没有增加任意图片上传或远程头像 URL。
- 工程测试器目前仅支持已安装依赖下的 Go/npm，禁网络；Linux `run_test` 在真实主机验证前明确阻止执行。其他语言、需要端口的测试及缺依赖下载不冒充可用。
- macOS 沙箱已验证文件、网络和系统工具边界；原生测试代码直接调用 launchd Mach/XPC API 是否被隔离仍未验证。不能把它描述为针对任意恶意代码的完整虚拟机隔离。
- 复核角色不能调用宿主写工具；项目测试代码自身仍可能写获准工程路径。交付验证要求测试前后内容一致，并与发布时工程摘要一致。构建/依赖目录和敏感路径不计入摘要。
- 写工具在同进程串行并检查期望哈希；外部编辑进程仍存在最终检查至替换之间的窗口，未实现跨进程 CAS。
- 真实模型的答案长度、模式判断和论证质量不能由结构性测试保证。正式讨论流程有边界，默认折叠让结果优先显示；复杂模型输出仍可能较长。
